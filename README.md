# Zhi Yang — Minimal Light personal website

Uses the official Minimal Light project's precompiled HTML theme assets, retrieved 2026-11-17 from https://github.com/yaoyao-liu/minimal-light . Upstream license is preserved in LICENSE-minimal-light. Theme CSS remains in assets/css; limited content-specific adjustments are in style.css.

This preview is buildless HTML, not a Jekyll/Markdown build. It can be deployed directly on GitHub Pages with .nojekyll. Edit index.html to update content. Run python3 -m http.server 8765 from this directory for local preview.

Deploy index.html, style.css, assets/, .nojekyll and LICENSE-minimal-light. Do not deploy preview/ (local historical snapshots).

Portrait and profile come from the supplied resume; InfoNav figure and paper come from the supplied manuscript. Resume-derived statuses should be confirmed before public release. Full resume is not included. No invented Scholar/LinkedIn links; upstream sample analytics and personal data were removed. Theme fonts use Google Fonts with local system fallback. Dark mode follows the system preference.
